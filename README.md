# Портфолио Антона Миненко

Статическая страница для работодателей: описание трёх личных продуктов, задачи, собственный вклад, скриншоты и короткие видео.

Публикуемые файлы находятся в `dist/`. Локальные сценарии записи, исходные кадры и результаты проверок находятся в игнорируемой `.cache/`.

Новостной бот представлен сохранённым материалом после LLM-обработки; видео не изображает новый запуск модели или отправку сообщения. Для прототипа самовывоза и сайта сообщества записаны работающие локальные интерфейсы 9 октября 2026 года. Дополнительные снимки Android-приложения относятся к предыдущей демонстрации тестового заказа.

Коммерческие документы, личные чаты, конфигурации доступа и исходники продуктов в публикуемый комплект не входят.
