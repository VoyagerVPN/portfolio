# Портфолио Voyager

Статическая страница для работодателей: описание трёх личных продуктов, задачи, собственный вклад, скриншоты и короткие видео.

Публикуемые файлы находятся в `dist/`. Локальные сценарии записи, исходные кадры и результаты проверок находятся в игнорируемой `.cache/`.

Новостной бот представлен сохранённым материалом после LLM-обработки; видео не изображает новый запуск модели или отправку сообщения. Для прототипа самовывоза и сайта сообщества записаны работающие локальные интерфейсы 9 октября 2026 года. Дополнительные снимки Android-приложения относятся к предыдущей демонстрации тестового заказа.

Коммерческие документы, личные чаты, конфигурации доступа и исходники продуктов в публикуемый комплект не входят.

Размещение: [voyagervpn.github.io/portfolio](https://voyagervpn.github.io/portfolio/) — GitHub Pages, репозиторий `VoyagerVPN/portfolio`, деплой автоматический при пуше в `main` (workflow `deploy.yml`). Прежний адрес `voyager-portfolio.vercel.app` не используется: домен `vercel.app` заблокирован провайдерами в России.

## Оформление True Order — 12 октября 2026, публикация и редизайн подачи — 14 октября 2026

Локальная версия визитки использует настоящую 3D-сцену True Order: `PlaneSurface`, `PlaneLights`, геометрию предметов и параметры света из `D:/Pet/True Order/src/widgets/geometric-grid`. Цвета, шумовой слой, шрифты Inter / Commissioner / Geist Mono и оформление кнопки перенесены из исходного сайта. Компоненты адаптированы к статической странице; сцена закреплена на длинном содержимом как на компьютере, так и на телефоне. Тексты проектов и контакты сохранены.

Публикуемый комплект в `dist/`: автономный `assets/trueorder-background.js`, `fonts.css`, локальные шрифты `assets/fonts/`, `favicon.svg`, страница `404.html`, OG-обложка `assets/og-cover.png`.

14 октября 2026: подача проектов переработана — полоса фактов по каждому проекту, теги технологий, блок доверия (рекомендательное письмо по запросу, сертификат английского C1 по CEFR, работа с AI-агентами), ссылка на живой True Order с реферальным пропуском (`true-order.ru/welcome?ref=portfolio`), плавное появление секций при прокрутке. Все три видео пересняты с непрерывной записью 25 кадров/с через Playwright recordVideo вместо слайдшоу из скриншотов.

Рабочая копия компонентов, адаптер, сценарии записи и проверки находятся в игнорируемой `.cache/`. Пересъёмка видео: поднять SBW (`npm run dev` в `D:/Pet/SBW`, порт 8787), True Order (`npm run dev -- --port 3012`) и статику новостей (`.cache` на 8791), затем `node .cache/record-smooth.cjs` / `record-ordering.cjs` и конвертация webm → mp4 (libx264, crf 20).

Проверены экраны 1440×1000 и 390×844: отсутствие горизонтальной прокрутки, появление всех секций при плавном скролле и при прыжке в конец страницы, работа ссылок.
